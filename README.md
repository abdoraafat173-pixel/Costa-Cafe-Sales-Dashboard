# ☕ Costa Cafe Sales Dashboard | Interactive Data Analytics Project

> **"Transforming Data into Actionable Insights"**

---

## 📌 Project Overview
An end-to-end data analytics project featuring an interactive Excel dashboard built to analyze and visualize coffee shop sales performance. The project uncovers key business metrics, customer purchasing patterns, and top-selling products to drive data-driven decision-making.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** PivotTables, PivotCharts, Slicers, and Dynamic Dashboard Layout.
* **Power Query (ETL):** Data extraction, transformation, cleaning, data type optimization, and formatting raw sales logs.
* **GitHub:** Version control and portfolio hosting.

---

## 🔍 Key Steps & Methodology
1. **Data Cleaning & Transformation (Power Query):**
   * Extracted time components from datetime fields.
   * Handled missing values, trimmed text anomalies, and standardized data types.
   * Filtered out unnecessary columns to optimize the dataset performance.
2. **Analysis & Dashboard Design:**
   * Created aggregated PivotTables for sales by product, category, and payment method.
   * Designed professional KPIs and interactive navigation buttons/slicers for a seamless user experience.
